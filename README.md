# مَدَد — MADAD

المستودع: https://github.com/HazemBS/Madad

اسم الحزمة الداخلي `rafd_v01`. الاسم الظاهر للمستخدم «مَدَد».

## اسم المشروع

مَدَد — MADAD

## فكرة المشروع

سوق جملة عربي يربط صاحب المتجر بالمورد في تطبيق واحد. يتصفح المتجر التصنيفات والمنتجات، يضيفها إلى السلة، ويؤكد الطلب. ويدير المورد منتجاته ويرى الطلبات الواردة عليها. الواجهة من اليمين إلى اليسار، والعبارة: «قيمة تتبادل، وأعمال تنمو».

إذا لم يُضبط اتصال Supabase يعمل التطبيق في وضع تجربة محلي واضح، من غير أن يتوقف.

## المشكلة التي يحلها

شراء الجملة عند المتاجر الصغيرة موزّع بين المكالمات ورسائل واتساب وقوائم أسعار غير محدّثة. يصعب مقارنة الموردين، ومعرفة الحد الأدنى للطلب، وتثبيت السعر لحظة التأكيد. مَدَد يجمع الكتالوج وسعر الجملة والسلة وتأكيد الطلب في مسار واحد، ويحسب إجمالي الطلب على الخادم حتى لا يغيّر الجهاز السعر.

## الفئة المستهدفة

- صاحب متجر صغير أو متوسط يريد الشراء بالجملة ومقارنة الموردين.
- مورد جملة يريد عرض منتجاته واستقبال الطلبات على ما يملكه فقط.

## أهم Features

- تعريف بالتطبيق ثم دخول بالبريد وكلمة المرور، أو إنشاء حساب متجر أو مورد.
- في وضع التجربة: «دخول تجريبي» لمتجر بقالة النور، و«دخول كمورد» لواحة الغذاء للجملة.
- تصفح التصنيفات والموردين والمنتجات والبحث وتفاصيل المنتج.
- تحديد الكمية، السلة، والمفضلة.
- تأكيد الطلب بدفع عند الاستلام أو تحويل بنكي، ثم شاشة النجاح وطلباتي.
- للمورد: لوحة مختصرة، منتجاته، إضافة منتج، والطلبات التي تضم منتجاته.
- كتالوج ومفضلة وطلبات من Supabase عند الاتصال، مع نسخة محلية لآخر بيانات ناجحة.
- إنشاء الطلب عبر دالة في قاعدة البيانات تقرأ السعر من جدول المنتجات.

## التقنيات المستخدمة

- Flutter وDart مع null safety، وواجهة عربية `Locale('ar', 'SA')` واتجاه RTL.
- `flutter_bloc` وإدارة الحالة عبر Cubit.
- `shared_preferences` للتخزين المحلي.
- Supabase: المصادقة، وPostgreSQL، وسياسات الصفوف، ودالة `create_secure_order`.
- `supabase_flutter` لعميل التطبيق.
- خط Tajawal وصور منتجات محلية داخل `assets/`.

لا تُستخدم Firebase ولا Dio. رفع صور المنتجات إلى Storage غير مبني، وتُعرض أيقونة التصنيف.

المسار داخل التطبيق: الشاشة، ثم Cubit، ثم المستودع، ثم Supabase أو الذاكرة المحلية.

## طريقة تشغيل المشروع

```bash
flutter pub get
supabase link --project-ref YOUR_PROJECT_REF
supabase db push
```

التشغيل المتصل بـ Supabase. ضع القيم مكان الأقواس، ولا تكتبها داخل الملفات. المفتاح هو المفتاح العام `anon` فقط، وليس مفتاح الخدمة:

```bash
flutter run \
  --dart-define=SUPABASE_URL=[YOUR_SUPABASE_URL] \
  --dart-define=SUPABASE_ANON_KEY=[YOUR_SUPABASE_ANON_KEY]
```

من داخل Cursor يمكن الضغط على Debug بعد اختيار الإعداد «مَدَد»، إذا وُجد ملف محلي `dart_defines.json` وغير مرفوع إلى Git.

من غير المتغيرين يبدأ وضع التجربة المحلي:

```bash
flutter run
```

التحقق والبناء:

```bash
flutter analyze
flutter test
flutter build apk --debug
```

التسجيل كمتجر يكتب الدور `customer`. التسجيل كمورد يكتب `supplier` وينشئ منشأة المورد. لا يستطيع المستخدم تغيير دوره لاحقًا من التطبيق. تأكيد البريد أُوقف على مشروع المسابقة حتى يدخل المجرّب مباشرة بعد إنشاء الحساب.

## التحديات أثناء التطوير وكيف حُلّت

- شريط منتج الجملة ضاق عن جملة «إضافة إلى السلة»، ثم صار الزر بعرض الشاشة وبدا كبيرًا لأن الثيم يفرض ارتفاعًا على كل الأزرار. الحَل: زر بعرض النص وارتفاع ثابت، في الصف نفسه مع الكمية والقلب.
- خروج المورد كان يفتح صفحة المفضلة. تبويب حساب المورد هو الرابع، وبعد الخروج يصبح الحساب متجرًا والرابع في شريط المتجر هو المفضلة، وكان الانتقال يُلغى لأن الشاشة تُعاد بناؤها. الحَل: حفظ مسار التنقل قبل الخروج والانتقال إلى صفحة الدخول.
- رابط تأكيد البريد كان يفتح `localhost:3000` وتنتهي صلاحيته، لأن Supabase يوجّه الرسالة إلى عنوان موقع لا يستخدمه تطبيق الجوال. الحَل: إيقاف تأكيد البريد على مشروع المسابقة حتى يُنشأ الحساب وتُفتح الجلسة داخل التطبيق.
- سعر الطلب لا يجوز أن يأتي من الجهاز. الحَل: دالة `create_secure_order` تقرأ السعر من جدول `products` وتنشئ الطلب وبنوده في معاملة واحدة، مع سياسات صفوف تمنع المتجر من تعديل منتجات المورد.

## أدوات الذكاء الاصطناعي المستخدمة

استُخدم Cursor أثناء التطوير، والمساعد البرمجي داخله.

استُخدم في:

- بناء شاشات التطبيق العربية وربطها بـ Cubit.
- كتابة عميل Supabase ومستودع البيانات وهجرة الأدوار ودالة الطلب الآمنة.
- إصلاح تسجيل الدخول والخروج وشريط المنتج، وإضافة الاختبارات التي تحاكي الخادم من غير الاتصال به.
- صياغة هذا الملف وتشغيل أوامر التحليل والاختبار.

المراجعة النهائية للسلوك على المحاكي تمت يدويًا، ولم يُرفع مفتاح الاتصال إلى المستودع.
