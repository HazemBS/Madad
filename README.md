# مَدَد — MADAD

سوق جملة يربط أصحاب المتاجر بالموردين وتجار الجملة. هذه نسخة عرض تعمل ببيانات محلية، بلا خادم وبدون اتصال إنترنت أثناء الاستخدام.

## الفكرة

صاحب المتجر يفتح مَدَد، يستعرض الموردين والمنتجات، يقارن سعر الجملة والحد الأدنى، ثم يجهّز سلة ويؤكد الطلب ويتابع حالته من داخل التطبيق.

## المشكلة

شراء الجملة اليوم موزّع بين المكالمات وواتساب وقوائم أسعار غير محدّثة. لا توجد شاشة واحدة للمقارنة ولا مسار واضح للطلب والتتبع.

## المستخدم المستهدف

صاحب متجر صغير أو متوسط يريد الشراء بالجملة بهدوء، ومقارنة الموردين، وتجهيز طلبه دون مراسلات متفرقة.

## المزايا

- استعراض الموردين وتجار الجملة مع المدينة والتقييم وشارة «موثّق».
- استعراض المنتجات حسب ست تصنيفات.
- البحث عن منتج أو مورد.
- عرض سعر الجملة والوحدة والحد الأدنى والكمية المتوفرة.
- السلة، مع توصيل تجريبي يصبح مجانيًا من 500 ر.س.
- تأكيد الطلب باختيار الدفع عند الاستلام أو التحويل البنكي.
- متابعة حالات الطلب.
- حفظ المنتجات في المفضلة.
- ملف منشأة تجريبي وتسجيل خروج محلي.

## هيكل المشروع

```text
lib/
  app/                  تشغيل التطبيق، النطاق، والمسارات
  core/                 الثيم، الشعار، والمكوّنات المشتركة
  data/                 النماذج، البيانات التجريبية، والمستودع
  features/             الشاشات والمتحكمات حسب الميزة
  main.dart
```

منطق السلة والمفضلة والطلبات والجلسة في `ChangeNotifier`، والواجهة تقرأها عبر `MadadScope`. البيانات كلها في `data/mock/mock_catalog.dart` ويمكن استبدال المستودع لاحقًا بـ API دون تغيير الشاشات.

## طريقة التشغيل

```bash
flutter pub get
flutter run
```

اسم الحزمة الداخلي ما زال `rafd_v01` حتى لا يتغير معرّف أندرويد وiOS. الاسم الظاهر للمستخدم هو «مَدَد».

## رحلة المستخدم

1. شاشة البداية تعرض «مَدَد» والعبارة: قيمة تتبادل، وأعمال تنمو.
2. ثلاث صفحات تعريف، ثم «ابدأ الآن» أو «تخطي».
3. تسجيل الدخول برقم جوال سعودي، أو زر «دخول تجريبي».
4. الرئيسية: ترحيب، بحث، تصنيفات، موردون، وعرض التوصيل، والأكثر طلبًا.
5. تفاصيل المنتج: كمية، إضافة للسلة، وإضافة للمفضلة.
6. السلة ثم تأكيد الطلب ثم شاشة النجاح.
7. «تتبع الطلب» يفتح طلباتي، و«العودة للرئيسية» ترجع للتبويب الأول.

الشريط السفلي: الرئيسية، التصنيفات، طلباتي، المفضلة، حسابي.

## ما هو تجريبي

- لا يوجد Backend ولا تسجيل دخول حقيقي. أي رقم يبدأ بـ 05 ومكوّن من 10 أرقام يفتح الحساب التجريبي نفسه.
- الدخول التجريبي يستخدم الرقم `0512345678` وحساب «بقالة النور».
- المنتجات والموردون والطلبات السابقة بيانات محلية في الذاكرة.
- عنوان التوصيل ورقم الحساب البنكي للعرض فقط.
- تكلفة التوصيل ثابتة: 25 ر.س، ومجانية عند 500 ر.س فأكثر.
- التعريف يظهر في كل تشغيل جديد لأن النسخة لا تحفظ حالة الجهاز.
- صور المنتجات ملفات محلية مضمّنة، والشعار نصي. استبداله من `lib/core/widgets/madad_logo.dart` فقط.

## العرض الحالي

التطبيق يعمل بلا إنترنت. الكتالوج والمفضلة والسلة والطلبات والحساب كلها محلية داخل الجلسة. لا تُهيأ أي خدمة بعيدة عند التشغيل.

زر «دخول تجريبي» يفتح حساب «بقالة النور» على الجهاز. أي رقم جوال سعودي صالح من 10 أرقام يبدأ بـ 05 يفتح الحساب المحلي نفسه.

## بيانات العرض المحلية

| الحقل | القيمة |
| --- | --- |
| الجوال | 0512345678 |
| المنشأة | بقالة النور |
| صاحب الحساب | خالد العمري |
| المدينة | الرياض |
| العنوان | حي النسيم، شارع الأمير بندر، الرياض |

## التطويرات المستقبلية

- ربط المستودع بواجهة برمجة حقيقية.
- حسابات منفصلة للمتجر والمورد.
- حفظ الجلسة والمفضلة على الجهاز.
- صور منتجات حقيقية وشعار بصري.
- دفع إلكتروني وتتبع توصيل مباشر.
- إشعارات تغيّر حالة الطلب.

ملفات رَفْد القديمة في مجلد `core/` خارج `lib/` لم تُحذف، والتطبيق لا يستوردها.
